HERMES 2D: Web-based Device Simulator — Documentation

This browser-based 2D Technology Computer-Aided Design (TCAD) simulator solves the coupled Poisson and drift-diffusion equations for 2D semiconductor devices directly inside your browser using WebAssembly.

1. Input Deck Syntax Reference

All spatial coordinates (X_MIN, X_MAX, Y_MIN, Y_MAX, SIGMA_X, SIGMA_Y) are specified in micrometers (μm).

  • MESH X_MAX=<val> Y_MAX=<val> NX=<int> NY=<int> — Defines the 2D simulation domain dimensions and tensor-product grid resolution.
  • REGION MATERIAL=<MAT> X_MIN=<v> X_MAX=<v> Y_MIN=<v> Y_MAX=<v> — Assigns material regions. Supported materials include SILICON, GERMANIUM, OXIDE, and HFO2.
  • DOPING TYPE=<ACCEPTOR|DONOR> PROFILE=<UNIFORM|GAUSSIAN> CONC=<cm^-3> ... — Adds background or implanted impurity profiles (in cm−3). Gaussian profiles accept SIGMA_X and SIGMA_Y.
  • CONTACT NAME=<ID> TYPE=<OHMIC|SCHOTTKY> [WORKFUNC=<eV>] X_MIN=<v> X_MAX=<v> Y_MIN=<v> Y_MAX=<v> — Places electrical boundary contacts along edges or interfaces.
  • MODELS SRH=<ON|OFF> FIELD_MOB=<ON|OFF> LOMBARDI=<ON|OFF> — Enables Shockley-Read-Hall recombination, velocity saturation, and surface mobility degradation models. Aso support default parameter overriding by using VSATN=<val>, VSATP=<val>, MUN=<val>, MUP=<val>,TAUN=<val>,TAUP=<val>
  • SOLVE TYPE=<ID_VGS|ID_VDS> SWEEP=<CONTACT> FIXED=<CONTACT> V_START=<V> V_STOP=<V> V_STEP=<V> V_FIXED=<V> OUTFILE=<file.csv> — Runs a quasi-static DC voltage sweep and exports terminal currents in μA/μm.

2. Example Input Deck

MESH X_MAX=0.090 Y_MAX=0.022 NX=46 NY=23
REGION MATERIAL=HFO2      X_MIN=0.000 X_MAX=0.090 Y_MIN=0.000 Y_MAX=0.002
REGION MATERIAL=GERMANIUM X_MIN=0.000 X_MAX=0.090 Y_MIN=0.002 Y_MAX=0.012
REGION MATERIAL=OXIDE     X_MIN=0.000 X_MAX=0.090 Y_MIN=0.012 Y_MAX=0.022
DOPING TYPE=ACCEPTOR PROFILE=UNIFORM CONC=1.0e15 X_MIN=0.000 X_MAX=0.090 Y_MIN=0.002 Y_MAX=0.012
CONTACT NAME=GATE TYPE=SCHOTTKY WORKFUNC=4.55 X_MIN=0.030 X_MAX=0.060 Y_MIN=0.000 Y_MAX=0.000
SOLVE TYPE=ID_VGS SWEEP=GATE FIXED=DRAIN V_START=-0.30 V_STOP=0.80 V_STEP=0.05 V_FIXED=0.50 OUTFILE=iv_output.csv

3. Post-Processing & Visualization Guide

  • I-V Results Tab: Displays terminal drain current versus sweep voltage in Linear or Semilog scale alongside automatically extracted device parameters (Constant-Current Vth at 0.1 μA/μm, minimum Subthreshold Swing SS, peak transconductance gm, Ion, Ioff, and Ion/Ioff ratio). Drag the vertical bar between the plot and metrics panel to resize.
  • 2D VTK & Cutline Tab: Renders 2D scalar/vector field distributions on the left and a 1D cross-sectional cutline graph on the right. Choose between Auto (Turbo/Viridis), Turbo, Viridis, and Inferno colormaps, adjust Min/Max color bounds, click anywhere on the 2D device map to move the dashed cutline, and export the active 1D slice via Save Cutline CSV.
  • Solver Console: Monitors real-time Newton-Raphson convergence residuals and solver diagnostics. Drag the horizontal divider above the console to adjust its height.

4. Limitations/Known Issues:

  • One semiconductor region: This version currently supports only one type of semiconductor inside device. A mixture of two different semiconductor such as Germanium and Silicon is not allowed.
  • Contact naming Restriction: Only pre-defined contact names such as DRAIN, GATE, SOURCE, SUB, GATE1 and GATE2 is supported. User defined contact names are not supported in this version.
  • Limited Physical models: Currently doping dependent Caughey-Thomas mobility, Canali model for Field dependent mobility and Lombardi model for mobility degradation at interface is available. Also SRH recombination model is available. Other models will be gradually incorporated in future releases.
  • Uniform Rectangular Mesh: CUrrent Version uses a rectangular mesh uniform through whole region.
  • AC Simulation Not supported:The current Version does not support small signal AC analysis. Only Quasi static DC analysis is possible.
